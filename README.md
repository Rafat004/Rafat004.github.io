# 🚀 Md. Rafatul Islam — Portfolio Website

A modern, responsive portfolio website built with vanilla **HTML**, **CSS**, and **JavaScript**. Features a dark glassmorphism theme with animated starfield background, smooth scroll animations, and a typing effect.

## ✨ Features

- **Animated Starfield** — Canvas-based twinkling stars with periodic shooting stars
- **Glassmorphism Design** — Frosted glass cards with gradient borders
- **Scroll Reveal Animations** — Elements animate in as they enter the viewport
- **Typewriter Effect** — Dynamic hero tagline typed out character by character
- **Responsive Layout** — Mobile-first design with hamburger navigation
- **Dark Theme** — Elegant deep navy base with violet-to-cyan gradient accents

## 🛠️ Tech Stack

| Technology | Purpose |
|------------|---------|
| HTML5 | Semantic structure |
| CSS3 | Design system with custom properties, glassmorphism, animations |
| JavaScript (ES6+) | Canvas animation, IntersectionObserver, typing effect |
| Google Fonts | Inter & Outfit typography |
